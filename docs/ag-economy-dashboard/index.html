Why I Built This Dashboard

I created this dashboard while working on a research project that required extensive exploratory data analysis of Federal Reserve agricultural finance data. As I found myself repeatedly downloading, processing, and visualizing these datasets, I realized I needed a more efficient way to explore the data and share my findings with coauthors.

What started as a personal research tool quickly evolved into something more. I realized this dashboard could be valuable for:

  • Fellow researchers working with agricultural finance data
  • Students in courses I may teach, providing hands-on experience with real Federal Reserve data
  • Industry professionals and policymakers interested in agricultural credit conditions
  • Anyone curious about trends in the agricultural economy

I've given this dashboard a permanent home on my website for the future reference of myself, my students, my coauthors, and anyone else interested in exploring this data. It's a living project that will continue to evolve based on user needs and feedback.

About This Dashboard

This interactive dashboard provides comprehensive visualization and analysis tools for Federal Reserve agricultural finance data. It combines three key datasets to offer insights into the U.S. agricultural economy.

Data Sources

  • District Surveys of Agricultural Credit Conditions: Quarterly surveys from agricultural lenders across seven Federal Reserve Districts
  • National Survey of Terms of Lending: Detailed information on non-real estate agricultural loans
  • Commercial Bank Call Report Data: Comprehensive banking data on agricultural lending

Features

  • Interactive time series visualizations with zoom and pan capabilities
  • Multi-series comparison tools
  • Export functionality for charts (PNG) and data (CSV)
  • Summary statistics for selected data series
  • Automatic quarterly updates from Federal Reserve sources
